
# 🧩 Jigsaw Puzzle Game

## 📌 Project Description
The Jigsaw Puzzle Game is a desktop-based puzzle game developed using C# in Visual Studio 2022. It is created using Windows Forms App (.NET Framework).

In this game, users select an image from their computer, and the application divides that image into 9 puzzle pieces (3×3). Players arrange the pieces in their correct positions to complete the original picture.

## 🛠️ Technologies Used
- Programming Language: C#
- IDE: Visual Studio 2022
- Application Type: Windows Forms App
- Framework: .NET Framework
- Graphics Library: System.Drawing

## 🎮 Game Features
- Load an image from your computer.
- Automatically divide the image into 9 puzzle pieces.
- 3×3 puzzle board.
- Random arrangement of puzzle pieces.
- Drag and drop functionality.
- Rotate puzzle pieces by 90 degrees.
- Automatic piece placement when moved near its correct position and returned to the correct rotation.
- Timer to track playing time.
- Restart button to play again.
- Winning message when all puzzle pieces are correctly placed.
- Picture preview.

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open the `.sln` file in Visual Studio 2022.
4. Wait for the project to load.
5. Build the project.
6. Click the Start button to run the game.

## 📂 Main Project Components
- `Form1.cs` – Contains the main game logic and functionality.
- `Form1.Designer.cs` – Contains the Windows Forms design and controls.
- `Program.cs` – Starts the Windows Forms application.
- `ImageSlicer.cs` – Divides the selected image into puzzle pieces (if included in the project).
- `README.md` – Contains project documentation.
